# Outputs Directory

This directory contains all experimental results generated by the framework.

## File Structure

```
outputs/
├── dr_comparison_results.csv          # Table 5.1: 6 DR methods × 5 metrics
├── dr_comparison.png                  # Figure 5.1: DR method visualization
├── regime_comparison_results.csv      # Table 5.2: 4 noise regimes
├── discretization_results.csv         # Table 5.3: Threshold strategy comparison
├── discretized_scores.csv             # Discretized factor scores (500 samples × 4 factors)
├── all_rules.csv                      # All 36 generated rules (machine-readable)
├── rules_quantile.json                # Quantile strategy rules
├── rules_std.json                     # Standard deviation strategy rules
├── rules_domain.json                  # Domain expert strategy rules
├── rules_human_readable.txt           # Plain English rules (Appendix B)
├── viz_dr_comparison.png              # DR comparison visualization
├── viz_discretization.png             # Discretization strategy visualization
├── viz_factor_distributions.png       # Factor score distributions
├── viz_correlation_heatmap.png        # Feature correlation heatmap
├── sparse_ae_features.png             # Sparse autoencoder learned features
├── sparse_ae_model.pt                 # Trained sparse autoencoder weights
└── case_study/                        # Credit risk case study outputs
    ├── model_card.json                # ECB Guide compliance
    ├── rules_credit_risk.json         # SR 11-7 validation report
    ├── individual_explanations.json   # GDPR Article 22 explanations (5,000 applicants)
    ├── shap_importance.png            # Feature importance visualization
    └── factor_distributions.png       # Case study factor distributions
```

## Regenerating Outputs

All outputs can be regenerated by running:

```bash
cd code/
python run_all_experiments.py --method all
python run_regime_comparison.py
python case_study_credit_risk.py
```

See [REPRODUCTION_GUIDE.md](../REPRODUCTION_GUIDE.md) for detailed instructions.

## File Formats

### CSV Files
- **Delimiter:** comma (`,`)
- **Encoding:** UTF-8
- **Header:** First row contains column names
- **Missing values:** Empty string or `NaN`

### JSON Files
- **Encoding:** UTF-8
- **Indentation:** 2 spaces
- **Structure:** Nested dictionaries with metadata + results

Example structure for `model_card.json`:
```json
{
  "model_type": "PCA",
  "n_components": 4,
  "variance_explained": 0.519,
  "surrogate_r2": {
    "PC1": 0.823,
    "PC2": 0.891,
    "PC3": 0.754,
    "PC4": 0.777
  },
  "shap_completeness": {
    "pass_rate": 0.762,
    "mean_error": 0.095,
    "max_error": 0.821
  }
}
```

### PNG Files
- **Resolution:** 300 DPI (publication quality)
- **Format:** RGB color space
- **Size:** Typically 8×6 inches (2400×1800 pixels)
